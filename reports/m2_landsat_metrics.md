# М2: оптическая ветка Landsat 8/9

Ветка включена: **True**. Обучающих вырезок: 239; вода 152, лёд 87.

Исходные USGS Collection 2 Level-2, шесть каналов отражательной способности и QA через публичный API Microsoft Planetary Computer. Вырезки 6×6 км, около 30 м/пиксель; RGB используется только для просмотра.

Разметка — спутниковые даты Qiu с собственной ошибкой около 11 суток, а не ручная проверка каждого кадра. Исключены ±14 суток от ледостава/вскрытия и неправдоподобные даты. Облачность, тени, циррус, заполнение и насыщение отбрасываются; снег сохраняется. На русле нужно ≥30 пригодных пикселей и ≥35% покрытия.

Проверка последовательная по сезонам: каждый тестовый сезон строго позже всех обучающих. Дата, координаты и платформа не входят в признаки. Маски воды построены по лету 2018–2020; географический ориентир — существующая маска Sentinel-1. Метрики относятся к классификации вне обучения, не к точности дат закрытия переправ и не к экономии в планировщике.

Проверочные 136 вырезок относятся к 122 уникальным сценам; все вырезки одной даты остаются в одном сезоне.
