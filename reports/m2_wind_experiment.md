# М2: эксперимент с ветром ERA5

Фиксированный протокол: [M2_WIND_EXPERIMENT](../docs/M2_WIND_EXPERIMENT.md). Повторная архивная оценка фиксированных радарных признаков; рабочая модель не заменена.

Покрытие: 1126 из 1126 размеченных сцен до сезона 2022; исключено 0. Один снимок 2024 года не используется. Тесты одинаковы для всех вариантов. ERA5 — оценки реанализа, а не местные измерения ветра.

Основная проверка: 666 сцен четырёх сезонов 2019–2022. Дополнительная: 1111 сцен шести сезонов 2017–2022. Balanced accuracy — среднее долей правильно распознанной воды и правильно распознанного льда.

## Ограничения и применение

Маски русла построены до эксперимента по общему архиву. Нет полного исключения тестового сезона из подготовки снимков, признаки округлены, метки сами имеют ошибку. Поэтому абсолютное качество не является новой независимой проверкой полного М2.

Скорость и направление получены из ERA5 задним числом. В час съёмки они могли ещё не быть опубликованы; нужен отдельный опыт с оперативными погодными выпусками. Ветер на сетке не измеряет локальные волны, течение подо льдом, толщину льда или допуск дороги.

Веса, маски и прогнозы действующего М2 сохранены. Результат допускает только исследовательский вывод; автоматическая замена модели и предупреждения по порогу ветра не выполнены.

Исходные ответы и SHA-256: data/s1/wind/. Полные прогнозы, метрики, сезоны и диапазоны ветра: reports/m2_wind_*. Повторение:

```bash
python scripts/download_m2_wind.py --fetch  # только при отсутствии сохранённых ответов
python scripts/download_m2_wind.py          # повторное сопоставление без сети
python scripts/experiment_m2_wind.py
```
