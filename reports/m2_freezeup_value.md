# Дата ледостава для прогноза открытия: сколько стоит и может ли её дать М2

Разница A − B — сколько точности держится на дате ледостава. C — сколько из этого вернёт спутник. D — модель, обученная без этого признака (если она не хуже B, сервис стоит перевести на неё).
