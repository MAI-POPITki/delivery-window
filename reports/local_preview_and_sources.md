# Локальный просмотр ZXC и поиск новых данных

Проверено 13.11.2026 по Москве.

- Добавлены `start-local.cmd` для Windows и `scripts/run_local.py`.
  Лаунчер работает только в ZXC, открывает браузер после готовности сервера,
  включает перечитывание кода при сохранении, не делает pull, push или смену ветки.
  На Windows первая установка требует Python 3.12, Git и доступа к зависимостям.
- В opt-in локальном режиме боковая панель показывает ветку, коммит и наличие
  изменений. Есть кнопка очистки кеша данных Streamlit и перечитывания страницы.
  Обычный запуск публичного приложения от этой панели не зависит.
- Реальный Chromium на облачном Linux: открыта М1, видны `31/31` дней; исключений
  нет. Временно изменена подпись в импортированном модуле: она автоматически
  появилась в браузере, затем оригинал восстановлен и восстановление тоже
  отобразилось. Дополнительно открыты М2 и GloFAS без исключений.
- Windows CMD в этой Linux-среде не исполнялся. Автоматический запуск браузера
  на пользовательском Windows ещё требуется проверить самим запуском файла.
  Облачный сервер и Windows localhost — разные компьютеры.
- Добавлена ручная догрузка исторических недель Метео ДВ с общим с фоновым
  загрузчиком lock. Пять запросов реально дали 36 измерений одного поста 3045,
  из них 31/31 в требуемом последнем месяце. Старые времена первого получения
  сохранены; `prev_y` не импортируется; обучение и архив М1 не менялись.
- Отдельный реальный запрос поста 3042 вернул семь измерений Табаги; исходный
  ответ и SHA-256 сохранены, в Якутск они не подмешаны.
- Исправлены устаревшие фразы интерфейса «не получены текущие уровни» и «данные
  за 2026 отсутствуют»: они не учитывали отдельное хранилище живых наблюдений.
  При полном месяце интерфейс теперь указывает на оставшиеся задачи —
  совместимость нуля шкалы и пакет модели текущего года.
- Полный набор: **312 тестов, 119,334 с, OK**. Отдельно проверены сшивка
  недель, сохранение первого времени доступности, отказ без повреждения
  предыдущего ряда и запрет неподдерживаемых постов/неограниченной догрузки.
