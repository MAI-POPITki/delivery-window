## Исправления совместимости

### Спутниковый архив М2

Первый полный прогон после объединения обнаружил нарушение контрольных сумм:
повторная загрузка перезаписывала `stac.json` у базовых сцен, которые использовались
несколькими расчётами. Девять старых ссылок в трёх результатах указывали на прежние
байты метаданных; новые результаты — на обновлённую запись того же каталога.

Старые байты восстановлены из исходной ZXC и сохранены отдельными файлами
`stac-<sha256>.json`. Старые манифесты ссылаются на эти файлы с прежними SHA-256.
Новые записи каталога также сохраняются как неизменяемые версии; перестроение
читает точную версию, указанную в манифесте. Старый формат `stac.json` поддерживается.
Проверки целостности не отключались, маски и площади не подменялись.

### Начало сезона планировщика

Добавлен явный выбор дороги. Дата открытия соседней дороги у того же гидропоста
не используется автоматически. Без выбора допустима только единственная дорога.
Открытие до 10 т не задаёт начало сезона для 20 т. Для факта и графика нужны
источник и дата публикации; будущие сведения не используются.
Дата начала сезона остаётся ориентиром, а не юридическим допуском каждого рейса.

### Гидропосты и обучение

Архивы обучения и веса CatBoost сохранены. В официальном слое точные замеры,
значения без даты и текстовые сводки имеют разный смысл. Модель снега может
использовать только пригодный датированный замер снега на льду своего поста,
уже доступный на дату решения. Метаданные снежной модели описывают изменение
входа без переобучения весов.

Подготовка целей зимней М1 воспроизводит три замера 29.12.2022: Верхоянск 84 см,
Зырянка 81 см, Якутск 47 см. Пригодных новых целей открытия нет. Извлечение целей
начала таяния пока не реализовано; соответствующий статус теперь указан явно.
Новый слой уровней не подставлен автоматически в паводковую М1.

В README, сводке пользы и генераторе документов уточнены рабочий М2 и кандидат,

пара MAE v2 39,9/61,4 см за 7 суток на всех доступных датах повторной оценки

PDF паспорта и описания пересобраны; описание совпадает с файлом в приложении.
В объединённом реестре и графике: 213 строк, 72 названия дорог,

## Воспроизведение проверок

```bash
pip install -r requirements-data.txt
OKNO_HYDRO_AUTO_REFRESH=0 python -m unittest discover -s tests -v
python scripts/validate_data.py
```

Полный прогон: **277 тестов, все прошли** (116 секунд). Набор включает проверки интерфейса, всех семи регионов официального слоя,
сохранённых исходных ответов и регрессии по неизменяемости STAC, выбору дороги,
ограничению 10 т и прекращению запросов после повторных 429.

Отдельно воспроизведены все **27** сохранённых результатов М2 из спектральных
вырезок: контрольные суммы, маски, летняя база и площади совпадают.
Это проверка воспроизводимости, а не независимая оценка точности.

Валидатор данных: **70/70**. Прежние WARN А3 о малой выборке исторических окон,
преобразовании физических дат и сценарных экономических параметрах сохранены.
Все файлы весов `.cbm` побайтово совпадают с исходной ZXC `9e82f7b`.

Оперативная доступность внешних сервисов и качество нового сезона этим прогоном
не подтверждаются: тесты официального обновления выполняются без фоновой сети.
