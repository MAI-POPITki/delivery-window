# Как пользоваться страницей паводков

1. Откройте «Паводки → Общая оценка участка». На обзорной карте видны все
   семь участков проекта: Якутск, Ишим, Курган, Оренбург, Орск, Омск, Томск. Подписи русские.
   Наведение показывает оценку; выбор города — кнопкой под картой или полем
   «Участок реки» слева. На карте не добавляются вымышленные посты.
2. Укажите «Дату расчёта (архив)» и «На сколько суток вперёд». Все точки
   обзора рассчитываются на одну дату. Цвет — вероятность превышения q90
   уровня прошлых учебных лет: зелёный → красный. Серый означает отсутствие
   модели или данных на эту дату, а не отсутствие паводка и не разрешение проезда.
3. В блоке «Оцените обстановку» посмотрите прогноз уровня, диапазон и общий
   результат со спутником. Карта воды ниже — наблюдение на дату съёмки,
   а не предсказание будущего контура. Старый или плохой снимок отмечен явно.
4. В блоке «Рассчитайте доставку» укажите участок дороги, обоснованный порог
   уровня, объём, длительность, тарифы и подтверждённые мощности/допуски.
   Нажмите «Рассчитать план доставки». Результат и CSV имеют русские названия
   полей. Остаток для другого способа не объявляется доставленным.

Кнопка «Пример: паводок в Орске 11 апреля 2024» сразу выбирает реальный пост,
дату и общий результат; тарифы и подтверждения она не выдумывает.

Почему раньше была одна точка: открывалась только локальная карта выбранного
поста. Теперь перед ней есть общий обзор всех семи, локальная карта сохранена
для подробностей. У Кургана нет собственной М1 — он серый, доступен прямой
переход к спутниковым наблюдениям.

Почему были английские названия: их печатала картографическая подложка.
Теперь используется подложка рельефа Esri без подписей населённых пунктов,
названия участков добавляются из проекта на русском. Источник проверен на
реальных тайлах: прежняя CARTO-подложка начала отдавать API KEY REQUIRED.
Необходимые атрибуции Esri/USGS/NOAA и OpenStreetMap сохранены.

Это готовый сценарий просмотра и условного планирования по архивным данным,
не заявление об оперативном прогнозе 2026 года: текущих уровней в архиве нет.
Проценты относятся к уровню гидропоста, а не к вероятности проезда дороги.

Для подробных уличных карт используется OpenStreetMap с исходными русскими
названиями в России; рельеф Esri используется только в общем обзоре.
Омск и Томск добавлены только в спутниковом режиме.
