# Собственный М1 уровней воды: протокол до обучения

Зафиксировано 09.11.2026 до обучения и расчёта метрик.

Цель: суточное архивное значение уровня воды в сантиметрах над нулём конкретного
гидропоста на 1–7 суток вперёд. Это не площадь затопления и не допуск дороги.
Внешний GloFAS не используется как целевая разметка или как замена измерений.

Источник: Level-Sputnik (Головлев П.П., Иннокентьев А.И., 2026), публичные
`/api/posts_geojson`, `/api/post_summary`, `/api/series`; записи `gmvo` — АИС ГМВО,
`vodinfo` — отдельный источник публикации. Исходные ответы и SHA-256 сохраняются.
Отрицательные уровни допустимы. Дубли, неизвестные источники и нечисловые значения
не маскируются. Пропуски не интерполируются.

Пилот: Якутск 3045 и Ишим 11412 — только gmvo (2008–2023);
Оренбург 19063 и Орск 19054 — только vodinfo. Источники в одном ряду не смешиваются.
Курган 12014 не допускается: всего один полный год gmvo; водинфо имеет большие
разрывы. Систематическая сверка уровней и нулей по независимому источнику ещё нужна.

Модель: CatBoost регрессии изменения уровня, признаки — текущий уровень, точные
календарные лаги 1/3/7/14/30 суток, изменения, средние за 7/30 дней, сезон и горизонт.
Погода и спутник в этой первой модели не используются. Гиперпараметры фиксированы:
200 итераций, глубина 5, learning_rate 0.06, L2 10, seed 42. Подбор по тесту запрещён.

Для тестового года Y обучение использует цели только по Y−2 включительно;
Y−1 — выбор между CatBoost и простыми правилами по каждому горизонту и калибровка
интервалов; Y — полностью отдельная проверка. Минимум 8 полных учебных лет
(≥90% ежедневных значений). Тестовые годы: 2019–2023 для gmvo, 2019–2024 для vodinfo.
2024 год Оренбурга/Орска не используется для настройки модели, проверяемой в 2024.

Соперники: сохранение последнего измерения; медиана прошлых лет для календарного
дня; значение той же даты прошлого года. Сравнение на одинаковых строках.
М1 показывает, какой алгоритм выбран по предыдущему году; замена на простое правило
не называется выигрышем CatBoost.

Метрики: MAE в см по горизонтам 1/3/7 дней, отдельно апрель–июль и весь год;
покрытие 80%-интервалов, число прогнозов, полные строки по годам. Калибровка —
80-й процентиль абсолютных ошибок предыдущего года, без тестовых ошибок.
90%-интервал выигрыша: бутстрэп по целым тестовым годам (2000 повторов, seed 42).
Успех для точки и горизонта: нижняя граница выигрыша >0 относительно всех трёх
соперников; MAE апреля–июля ниже каждого соперника; покрытие ≥75%. Иначе статус
экспериментальный, отрицательный результат сохраняется.

Проверки реализации: будущее не влияет на признаки/прогноз; калибровка и обучение
строго раньше даты решения; точные лаги через пропуск не сдвигаются; нули/отрицательные
уровни сохраняются; старые данные не выдаются за наблюдения 2026 года; данные разных
станций и источников не подменяются. Исторический расчёт использует позднее полученный
архив наблюдений: это ретроспективная проверка, не восстановленный оперативный выпуск.
