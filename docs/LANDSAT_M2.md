# Landsat 8/9 в М2

## Источник и данные

Используется [USGS Landsat Collection 2 Level-2](https://www.usgs.gov/landsat-missions/landsat-collection-2-level-2-science-products)
через открытые STAC и Data API [Microsoft Planetary Computer](https://planetarycomputer.microsoft.com/dataset/landsat-c2-l2).
Такой источник согласован пользователем: Copernicus ограничивает прямое скачивание
Landsat, см. [объявление CDSE](https://dataspace.copernicus.eu/news/2026-1-16-landsat-8-and-landsat-9-collection-2-level-1-data-availability-copernicus-data-space).
На сайте источник указан как USGS / Microsoft Planetary Computer.

Семь точек Лены общие с Sentinel-1. Для каждой запрашивается окно около 6 × 6 км,
200 × 200 пикселей, приблизительно 30 м. Официальный Data API выдаёт численные
вырезки; исходные сцены размером в гигабайты не скачиваются. Шесть каналов:
blue, green, red, nir08, swir16, swir22; дополнительно QA_PIXEL и QA_RADSAT.
Сохраняются uint16, географические границы, CRS и время получения. Это спектральные
данные; цветной PNG создаётся отдельно для просмотра.

Отражательная способность: **DN × 0,0000275 − 0,2**, согласно
[USGS](https://www.usgs.gov/faqs/how-do-i-use-a-scale-factor-landsat-level-2-science-products).
Служебные QA перепроецируются методом ближайшего соседа.
Из QA_PIXEL исключаются fill, dilated cloud, cirrus, cloud и shadow; **snow bit 5
сохраняется**. Насыщенные выбранные каналы и terrain occlusion исключаются по
QA_RADSAT. Требуются ≥30 пригодных пикселей и ≥35% пригодного русла.

## Обучение и проверка

Для оптики обучена отдельная ветка `models/m2_landsat_ice.cbm`: спектральные
квантили/разброс и индексы NDSI, NDWI, NDVI. Весами радарной модели оптика
не обрабатывается. Модель Sentinel-1 сохранена.

Скачано 369 исторических вырезок 2018–2024 гг. После контроля качества и
разметки осталось 239: 152 «вода», 87 «лёд». Эталон — внешний ряд спутниковых
дат Qiu, с собственной ошибкой около 11 суток; это не ручная разметка каждого кадра.
Исключены ±14 суток от событий и неправдоподобные даты. Калибровка масок воды —
лето 2018–2020; исходная маска Sentinel-1 задаёт географический ориентир русла.

Проверка последовательная: тестовый гидрологический сезон 2021, 2022, 2023 или
2024 строго позже всех обучающих. Дата, координаты и номер спутника в признаки
не входят. На 136 вырезках из 122 сцен: 135 правильных ответов, accuracy 0,9926,
balanced accuracy 0,99. Полные таблицы — `reports/m2_landsat_metrics.md`,
проверочные предсказания — `reports/m2_landsat_oof.csv`.
Это оценка для пригодных кадров вне переходного периода относительно ряда Qiu.
Она не измеряет точность дат открытия дорог, грузоподъёмность льда и экономию.

Включение требует не менее 40 проверочных вырезок, минимум 10 каждого класса,
трёх проверочных сезонов, balanced accuracy ≥0,8 и F1 обоих классов ≥0,75.
Манифест `models/m2_landsat.json` содержит условия проверки, SHA-256 весов,
масок и обучающих признаков. Снимки с облаками или недостаточным покрытием
получают статус отсутствия оценки, а не вероятность воды по умолчанию.

## Автоматическая работа и даты

Во вкладке «Карточка пути» расположен блок **«Landsat 8/9 — снимки и оптическая М2»**.
Он показывает источник, дату, пригодное покрытие, оценку и сам снимок с маской русла.
Карты М2 и сверка с М1 выбирают наиболее новое доступное наблюдение Sentinel-1
или Landsat. Уверенное противоречие разных спутников в пределах 48 часов даёт
статус неопределённости. Свежая сверка ограничена 14 сутками; старые кадры видны
с предупреждением. Количественные прогнозы М1 не пересчитываются по картинке.

Для Landsat записаны время съёмки, поступление данных и время появления оценки.
Наблюдение не допускается в расчёт до получения данных и обучения модели.
Исторические вырезки, обработанные сейчас, не становятся доступными задним числом.
Для старых Sentinel-1 время публикации неизвестно: сохранено существующее поведение
с фильтром по дате съёмки. Проверка классификатора по сезонам отличается от
бэктеста доступности данных в настоящем времени.

При запуске основной части приложения один фоновый процесс проверяет источник
каждые 6 часов, галерея обновляется раз в минуту. Обычный повторный проход пары
Landsat — около 8 суток, а облачность и слабое зимнее освещение увеличивают пробелы.
Например, в первоначальной живой загрузке последние пригодные кадры по точкам
датированы 16.09–28.10.2026. Это архивные обзоры, а не снимки 13 ноября.
В полярную ночь оптической оценки может не быть; радарная ветка продолжает работать.

`data/landsat/chips/` и `previews/` — восстанавливаемый кэш, исключённый из git.
Индексы, проверочные признаки, предсказания и статусы сохраняются в репозитории.
При сбое источника сохраняются прежние наблюдения. После нового клонирования
последние вырезки восстанавливаются автоматически.

```bash
# Первичная подготовка и повторное обучение с проверкой:
pip install -r requirements-data.txt
python scripts/train_m2_landsat.py --download

# Докачка и применение фиксированной проверенной модели:
python scripts/download_landsat.py --days 90

# Детерминированная проверка без фоновых сетевых запросов:
OKNO_DAILY_IMAGERY_AUTO_REFRESH=0 OKNO_LANDSAT_AUTO_REFRESH=0 OKNO_GAOFEN_AUTO_REFRESH=0 OKNO_HYDRO_AUTO_REFRESH=0 python -m unittest discover -s tests
```

В GitHub workflow также добавлено обновление Landsat. Расписание GitHub выполняется
только в ветке по умолчанию; в `kirill` автономность обеспечивает сервер Streamlit.
Без работающего сервера требуется ручной workflow из `kirill` или внешний планировщик.
Новые неразмеченные кадры проходят применение модели; автоматическое переобучение
на неизвестном состоянии льда не выполняется.
