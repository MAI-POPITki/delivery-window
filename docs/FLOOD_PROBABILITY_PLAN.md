# Вероятности превышения уровня: протокол 10.11.2026

Цель — событие «измеренный уровень на целевую дату ≥ заданного порога»,
не затопление дороги. Существующие годы 2019–2025 уже просмотрены: это
повторная ретроспективная оценка новой вероятностной надстройки. Независимым
тестом её называть нельзя. Параметры ниже фиксируются до её расчёта.

Модель М1 v2 не переобучается. Для года Y используются её ошибки за Y−1,
отдельно по горизонту и апрелю–июлю/остальным месяцам (минимум 60, иначе весь год).
Нормированная ошибка = (факт−М1)/max((верх−низ)/2,1 см). Вероятность превышения:
(число ошибок ≥ (порог−текущий прогноз)/текущий масштаб +1)/(N+2).
Так вероятность не становится ровно 0 или 100% на конечной выборке.
Это эмпирическая оценка с предположением переносимости прошлых ошибок.

Порог проверки — q80/q90 измеренных уровней апреля–июля только учебных лет
по Y−2. Проверяем апрель–июль года Y, горизонты 1/3/7. Соперники: частота
превышений в прошлом апреле–июле и сохранение текущего уровня, также с
эмпирическим распределением ошибок прошлого года. Brier score (меньше лучше),
skill против каждого соперника, таблица калибровки, число событий/несобытий;
90% bootstrap-интервал выигрыша по годам (2000, seed42).
Новый метод допускается как подтверждённый на повторной оценке только если
нижние границы выигрыша >0 против обоих соперников. Любой отрицательный
результат публикуется. Никакого перевода этих процентов в шанс проезда нет.

М2: для доказательства требуется независимая геопривязанная разметка того же
времени, а не SCL и не нарисованные по нашему результату контуры. М3: нужны
реальные рейсы для экономического эффекта; математическая оптимальность
сама по себе не подтверждает пользу прогнозов.
