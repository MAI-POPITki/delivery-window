# М2 паводков: протокол первой версии, 10.11.2026

До расчёта масок фиксируется алгоритм открытой воды Sentinel-2 L2A.
Источник: Copernicus Sentinel-2 через Microsoft Planetary Computer STAC,
`sentinel-2-l2a`. Все сцены, время съёмки/создания, исходные URL без временных
SAS-токенов, исходные вырезки DN, XML радиометрии и SHA-256 сохраняются.

Пилот: пять существующих точек паводков, квадрат 12×12 км вокруг координат
гидропоста из манифестов (включая Курган, которому не хватает ряда для М1).
Сетка UTM 20 м. Каналы B02/B03/B04/B08/B11 и SCL; bilinear для спектральных
каналов, nearest для SCL. Коэффициенты reflectance=(DN+BOA_ADD_OFFSET)/
BOA_QUANTIFICATION_VALUE читаются из XML, не выводятся по дате сцены.
Исходный DN=0 остаётся NoData. Индексы с неположительным знаменателем неизвестны.

Валидные классы SCL: 4,5,6. Остальные (включая снег, тени, облака и неопределённое)
не считаются ни сушей, ни водой. Вокруг облаков/теней/снега/неопределённого SCL
1,2,3,7,8,9,10,11 исключается ещё 40 м (2 пикселя). NoData исключается отдельно.
Открытая вода: MNDWI=(green−SWIR)/(green+SWIR)>0.1,
NDVI=(NIR−red)/(NIR+red)<0.3, NIR<0.15. Это фиксированное спектральное правило,
не обученная на разметке затоплений нейросеть. Пороговые значения экспериментальны.

Дополнение v1.1 после диагностики ноябрьских сцен, до публикации: водный класс
SCL=6, не подтверждённый спектральным правилом, становится неизвестным, а не сушей.
Пороги воды не менялись. При IoU двух водных масок <0.5 интерфейс предупреждает
о сильном расхождении. Это изменение контроля качества по результатам осмотра,
не независимая валидация. Исходная пригодность до воздержания используется
в диагностике IoU, чтобы не скрывать несогласие искусственным ростом метрики.

База — три разных дня предыдущего июня–августа с минимальной облачностью
целой сцены в том же MGRS-тайле. Голосование по отдельным пикселям:
база определена при ≥2 валидных наблюдениях и доле воды ≤1/3 либо ≥2/3.
Продукты базы с датой генерации позже генерации текущего снимка исключаются:
более поздняя переработка старого снимка не считается доступной в прошлом.
Промежуточные значения неизвестны. Новая вода = вода сейчас AND уверенная суша
в базе. База обязана быть раньше текущего снимка. Изменение относительно летней
базы не доказывает чрезвычайное затопление: сезонные изменения также возможны.
Площади — число пикселей×400 м², только по наблюдаемой территории; без экстраполяции.

Архивный пример: апрель 2024 (Якутск — май 2024), выбор текущей сцены по
минимальной облачности сцены внутри заданного интервала; локальная пригодность
измеряется уже на вырезке. Нельзя подбирать пороги по красивому результату.
Непригодные сцены и отсутствие сцены/базы не подменяются.
При локальной видимости <50% — неполное наблюдение. В интерфейсе всегда дата,
возраст и охват. Снимки не выбираются позже даты просмотра; учитывается также
дата генерации продукта. Архив получен позднее — это не восстановленный
оперативный выпуск. Даже качественный старый снимок не становится текущим.

Проверка: точные даты/CRS/совмещение сетки, реальные данные/хеши, снег/облака/
тени/NoData не становятся сушей или водой, база только из прошлого, маски площади
и неизвестного, доступность интерфейса без тяжёлых GIS-библиотек. RGB и маски
публикуются рядом для визуальной проверки. Согласие с SCL water — диагностика,
не независимая точность: оба продукта используют один снимок. Без независимой
разметки IoU/F1 затопления и гарантия безопасности дорог не заявляются.
