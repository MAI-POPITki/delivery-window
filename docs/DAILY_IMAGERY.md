# Ежедневные снимки MODIS и VIIRS

Во вкладке «Карточка пути» добавлен блок **«MODIS / VIIRS — ежедневные снимки NASA»**.
Он показывает цветные суточные мозаики для семи существующих спутниковых точек Лены.
Можно выбрать точку и дату и сравнить MODIS с VIIRS рядом, переключить спутник,
скачать PNG или открыть исходное изображение NASA.

## Источник

Открытый [NASA GIBS / ESDIS](https://www.earthdata.nasa.gov/data/tools/gibs),
те же изображения доступны в [NASA Worldview](https://worldview.earthdata.nasa.gov/).
Авторизация и ключ API не нужны. Каталог:
https://gibs.earthdata.nasa.gov/wmts/epsg4326/best/1.0.0/WMTSCapabilities.xml

Используются четыре ежедневных слоя Corrected Reflectance True Color:

- MODIS Terra и MODIS Aqua: исходные цветовые каналы 250–500 м;
- VIIRS NOAA-20 и NOAA-21: цветной обзор примерно 750 м.

У VIIRS есть каналы 375 м, однако выбранный цветной продукт не объявляется
снимком с таким разрешением. Сетка показа GIBS 250 м также не превращает
исходные данные в изображение с детализацией 250 м. Пользователь согласовал
приоритет нужных фотографий, без обязательного разрешения 250–375 м.

Для каждой точки запрашивается окно около 80×80 км, 512×512 пикселей,
WMS 1.1.1, EPSG:4326. BBOX задаётся в порядке долгота/широта. Это обзор
окрестностей реки; разрешения недостаточно для оценки отдельных машин или
несущей способности ледовой переправы.

## Даты, покрытие и применение

Время запроса не заменяет дату мозаики. Проверяется наличие точного дня
в каталоге NASA с учётом разрывов. Если день не опубликован, предыдущий кадр
не подставляется под новую дату. Суточная мозаика может включать несколько
пролётов, поэтому точное время отдельной сцены здесь не указывается. Все даты
мозаик — UTC; время фактического получения и SHA-256 сохраняются отдельно.

Прозрачные и полностью чёрные изображения помечаются как отсутствие данных.
Частично чёрное окно отмечается как неполное. Это проверка заполнения картинки,
не физическая маска облаков: очень тёмная вода также может попасть в эту проверку.
Белая облачная область не получает статус «без облаков» или «лёд». Облачность
автоматически не определяется; в полярную ночь возможны пробелы.

Эти PNG — визуальные обзоры, а не калиброванные спектральные каналы. Они
не подаются в классификаторы Sentinel-1/Landsat, не превращаются в P(лёд),
не меняют численные прогнозы М1/М2 или исторические расчёты. Модель для такого
масштаба и отдельный контроль качества потребуются перед численным применением.

## Автоматическая работа

Один фоновый загрузчик на процесс сервера проверяет публикации раз в 6 часов;
галерея проверяет обновления раз в минуту. Приложение остаётся доступным во время
загрузки. Скачиваются семь последних дней, повторно проверяются последние три
даты, поскольку суточные мозаики дополняются. Накопленная история — до 31 дня.
Сбой источника сохраняет имеющиеся изображения с их исходными датами.

Метаданные находятся в `data/daily_imagery/catalog.json` и `snapshot.json`.
`previews/` — восстанавливаемый кэш PNG, исключённый из git. При новом клонировании
он восстанавливается фоновым загрузчиком. В workflow добавлен такой же сбор.
GitHub cron работает только из ветки по умолчанию; в `kirill` автоматическую
работу обеспечивает запущенный сервер приложения.

```bash
python scripts/download_daily_imagery.py --days 7

# Офлайн-проверки без сетевых фоновых загрузчиков:
OKNO_DAILY_IMAGERY_AUTO_REFRESH=0 OKNO_LANDSAT_AUTO_REFRESH=0 OKNO_GAOFEN_AUTO_REFRESH=0 OKNO_HYDRO_AUTO_REFRESH=0 python -m unittest discover -s tests
```
