# Независимая разметка М2: протокол до теста, 10.11.2026

Sen1Floods11 v1.1, Cloud to Street, Bonafilia et al. CVPRW 2020.
Только LabelHand, не автоматическая разметка S2IndexLabelWeak.
Официальные train/valid/test CSV сохраняются с SHA-256. Bolivia — отдельное
событие вне этих разбиений и отдельный тест переноса. Тестовые метрики ранее
в проекте не считались. После просмотра теста параметры не меняются.

Фиксированная подвыборка обучения: первые 8 файлов по имени каждого события
официального train; валидация: первые 3 каждого события valid. Проверка:
весь официальный test (90) и вся Bolivia (15). Пересечение имён запрещено.
Это ускоренный эксперимент, не результат обучения на полном train.

Вход S2Hand — 13 каналов Sentinel-2 L1C TOA /10000. Проверяются CRS, форма,
геопривязка с LabelHand. Используются B03/B04/B08/B11, MNDWI, NDVI, NDWI,
локальные средние 5×5 MNDWI/NIR. NaN/NoData не считаются сушей.
Модель-кандидат: CatBoostClassifier iterations200 depth5 lr.06 L2=10 seed42;
до 5000 равномерно случайных валидных пикселей каждого обучающего файла.
Порог из {0.3,0.4,0.5,0.6,0.7} по F1 воды только на valid.

Соперники: текущее спектральное правило MNDWI>.1 NDVI<.3 NIR<.15;
NDWI>0; всегда суша. SCL в наборе отсутствует — сравнивается спектральный
компонент, а не вся локальная L2A-маска облаков. Обязательно указывается
различие TOA/BOA: модель не заменяет локальный М2 автоматически.

Метрики: TP/FP/FN/TN, IoU/F1 воды, accuracy, coverage всех размеченных пикселей,
по каждому чипу и событию, pooled и среднее по событиям. Неопределённый прогноз
на размеченной воде учитывается как пропуск (FN), на суше — отдельно как abstain.
95% bootstrap-интервал разницы IoU по целым чипам, 2000 seed42; зависимость
соседних чипов раскрывается. Отдельная Bolivia — более строгая проверка события.
Полезный кандидат: положительная нижняя граница улучшения над текущим правилом
на основном тесте и IoU не хуже правила на Bolivia. Равенство зимнему М2
только по accuracy заявлять нельзя: там другая задача и баланс классов.
