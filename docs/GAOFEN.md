# Гаофэнь-3: автоматическая загрузка обзорных снимков

Ветка `kirill`, проверка источников 12 ноября 2026 г. (UTC).

Работающий источник — [официальный каталог NSOAS](https://osdds.nsoas.org.cn/HighResolutionSatellite).
Публичный поиск `POST /api/metaData/search` и шлюз `/loadImg/browse/` позволяют
без регистрации получать метаданные и обзорные PNG реальных радарных сцен GF-3.
Вручную проверено скачивание сцены
`GF3_MDJ_FSII_053957_E128.7_N62.6_20261109_L1A_HHHV_L10007496592`:
PNG 1685 × 2155, 2 592 980 байт. Это изображение над Леной и Якутском от 9 ноября 2026 г.

## Что загружается

- Семь текущих точек М2 на Лене: Ленск, Олёкминск, Покровск, Якутск, Сангар,
  Жиганск и Кюсюр. Координаты берутся из фактического индекса Sentinel-1;
  при его отсутствии используются общие ориентиры из `okno/s1_points.py`.
- Для каждой точки ищутся сцены за 90 дней. Выбирается самая новая сцена,
  покрывающая **всю** область приблизительно 3 × 3 км. Пересечения краем недостаточно.
- `data/gaofen/snapshot.json` хранит дату проверки, идентификаторы, даты съёмки,
  поляризацию, контуры, ссылки на источник и SHA-256 скачанных PNG.
- `data/gaofen/previews/` — восстанавливаемый локальный кэш изображений, исключённый из git.
  На одну точку скачивается один последний обзор; одинаковые сцены не дублируются.
- Ограничения: не более 300 результатов на точку и 12 МиБ / 25 млн пикселей на PNG.
  Ошибки источника сохраняют предыдущий корректный снимок. Неизвестные контуры,
  HTML вместо PNG, повреждённые изображения и кадры без полного покрытия отбрасываются.

## Автоматическое обновление

При запуске основной части Streamlit работает один фоновый загрузчик на процесс:
проверяет необходимость обновления каждый час, обращается к источнику раз в 6 часов.
Первый запуск и потеря кэша также вызывают загрузку. Снимки появляются по мере
публикации спутниковых сцен: ежедневная проверка не означает ежедневную съёмку.
Галерея во вкладке «Карточка пути» обновляется раз в минуту.

```bash
python scripts/download_gaofen.py
python scripts/download_gaofen.py --points yakutsk_crossing --days 90
```

Команда возвращает код 2, если хотя бы одну выбранную точку обновить не удалось.
Для автономных тестов: `OKNO_GAOFEN_AUTO_REFRESH=0`.
Полная проверка без сетевых фоновых задач:
`OKNO_GAOFEN_AUTO_REFRESH=0 OKNO_HYDRO_AUTO_REFRESH=0 python -m unittest discover -s tests`.
В ежедневный workflow также добавлен загрузчик. GitHub запускает расписание
только из ветки по умолчанию; автономность `kirill` обеспечивает именно процесс
Streamlit, без изменений `main`. При остановленном сервере требуется запуск workflow
в `kirill` вручную или внешний планировщик, вызывающий эту команду.

## Граница применения в М2

**Обзорные PNG служат только для просмотра.** В них нет калиброванных VV/VH в дБ,
из которых обученная М2 извлекает признаки. Большинство найденных сцен GF-3 имеют
HH/HV; найденная сцена с VH/VV также требует проверки обработки и разрешения.
Поэтому `ml_ready` всегда `false`; изображения не попадают в `data/s1`, прогнозы,
автоматические даты событий и факты журнала. Снимки, скачанные сейчас, также не
являются доказательством их доступности в момент исторического прогноза.

Для численного использования GF-3 нужны исходные радарные продукты, их калибровка,
геокодирование, согласование каналов и проверка отдельного классификатора на сезонах
вне обучения. Текущий каталог не выдаёт ссылку на исходный продукт (`productFileLocation=null`).
Автоматизация покупки, заказа или регистрации не выполняется.

Другие проверенные источники: [CNSA-GEO](https://www.cnsageo.com/) недоступен из среды
загрузки; [CRESDA](https://data.cresda.cn/) возвращает 403.
В [CASEarth](https://data.casearth.cn/dataset/2) проверено чтение настоящего GF-1
GeoTIFF по HTTP Range, но 137 сцен этого набора относятся к Южной Азии.
Открытые GF-1/GF-6 — оптические данные, для них также нужна отдельная модель.

Источник изображений: Национальный центр применения океанических спутников Китая (NSOAS).
При использовании данных в публикациях необходимо указать источник
https://osdds.nsoas.org.cn/ и поблагодарить NSOAS за предоставленные данные,
согласно уведомлению на главной странице портала.
