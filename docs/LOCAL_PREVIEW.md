# Как видеть изменения ZXC

Локальный сервер запускает файлы текущей рабочей копии. Пуш в GitHub для просмотра
своих правок не нужен. После сохранения Python-файла Streamlit автоматически
перезапускает страницу. Для изменённых данных есть кнопка «Перечитать данные».
В боковой панели видны ветка, коммит и наличие незакоммиченных изменений.

## На Windows

Нужны Python 3.12 и Git. В своей папке `delivery-window`, находясь в ZXC,
запустите двойным щелчком `start-local.cmd`. Он создаст `.venv`, установит
зависимости из `requirements.txt` и откроет браузер после запуска сервера.
При последующих запусках уже установленные версии используются повторно.
Если возникнет ошибка, окно останется открытым с её текстом.

Адрес: http://localhost:8501 . Сразу паводки: http://localhost:8501/?module=flood .
Окно терминала должно оставаться открытым; остановка — Ctrl+C.

## В существующем Python-окружении

```bash
python -m pip install -r requirements.txt
python scripts/run_local.py
```

Для сервера без открытия браузера:

```bash
python scripts/run_local.py --host 0.0.0.0 --port 8501 --no-browser
```

Автообновление источников включено по обычным настройкам приложения. Воспроизводимый
просмотр сохранённых файлов возможен с `OKNO_HYDRO_AUTO_REFRESH=0` и
`OKNO_FLOOD_AUTO_REFRESH=0`; при этом загрузка новых данных отключена.

## Облачная среда и публичный сайт

`localhost` относится к компьютеру, на котором запущен сервер. Облачный localhost
не открывает сервер на вашем Windows-компьютере. Для просмотра облачного процесса
нужен доступный в клиенте проброс порта/preview. Если такой возможности нет,
используйте запуск Windows выше. Это отдельный вопрос от работоспособности приложения.

Текущий публичный Streamlit-адрес не показывает сборку ZXC: на проверке 13.11.2026
по Москве там отсутствовал раздел паводков. Локальный запуск не меняет хостинг,
не делает коммитов, пушей или переключений веток. При запуске из другой ветки
скрипт попросит сначала выбрать ZXC.
