# Общий результат М1 → М2 → М3

По умолчанию «Паводки → Общая оценка участка» открывает общий результат:
ожидаемый уровень и вероятность выбранного события, наблюдаемую воду с
качеством и возрастом снимка, общую карту дорог и воды, форму плана доставки.
Модели больше не требуется открывать как три отдельных пользовательских задачи.
Отдельные вкладки сохранены для объяснения и проверок.

Общий контекст — один пост и одна дата решения. Прогноз направлен в будущее;
спутник только наблюдает прошлое/настоящее относительно решения. Поздняя
переработка снимка не считается доступной раньше генерации продукта. Если
снимок устарел, закрыт облаками или методы расходятся, это явно указано.
Никакого общего процента проезда перемножением М1 и М2 не создаётся.
Для решения о рейсе остаются обязательными подтверждённые условия дороги.

Добавлены реальные сцены 2023/2025 для сопоставления с собственным М1.
Отбор новых сцен: последняя дата с локальной видимостью SCL ≥50%; иначе
максимальная локальная видимость. Облачность большого тайла больше не
используется как замена видимости 12-км участка. Все кандидаты и локальные
доли записаны в manifest.json. Базовые пороги воды не менялись по результатам
независимого теста.

Ввод М3 сохраняется между вкладками. При смене поста порог и его основание
сбрасываются: сантиметры над разными нулями нельзя переносить между реками.

## Что теперь проверено независимо

[Полный тест Sen1Floods11](../reports/flood_m2_benchmark.md):
кандидат F1 воды 0.933, IoU 0.874 против 0.877/0.781 текущего спектрального
компонента. 95%-интервал выигрыша IoU по чипам +0.059…+0.130.
Отдельная Bolivia: F1 0.908, IoU 0.831; интервал улучшения включает ноль.
Разные события не одинаковы: Ghana F1 около 0.75, Paraguay около 0.78.

Это независимая ручная разметка, а не SCL и не разметка нашего результата.
Но проверялось выделение воды на L1C, не вся цепочка «L2A → затопление дороги
→ фактическая доставка». Поэтому кандидат сохранён отдельно, а не молча
подставлен в карту с обещанием локальной accuracy 98%.
