# М1 паводков v2: квантильный эксперимент

Зафиксировано 10.11.2026 до обучения v2. Результаты v1 за 2019–2024 уже
просмотрены: этот период является повторной оценкой, а не нетронутым тестом.
2025 год Оренбурга и Орска (до 09.09) — дополнительный, ранее не включённый
в отчёт год; это неполный год. Архив получен позднее, оперативные версии не восстановлены.

Задача и источники остаются прежними: реальные уровни конкретного поста в см,
горизонты 1–7 суток. Новых вымышленных измерений, погоды или опасных отметок нет.
Признаки и параметры CatBoost те же, что у v1. Единственное изменение модели:
MultiQuantile 0.1/0.5/0.9 вместо RMSE. Медиана соревнуется с тремя базовыми
правилами по MAE предыдущего года отдельно на каждом горизонте.

Для года Y обучение использует цели по Y−2; Y−1 выбирает метод и калибрует
интервалы; Y используется только для оценки. Для выбранного CatBoost применяется
CQR: score=max(q10−факт, факт−q90). Поправка — порядковая статистика
ceil((n+1)*0.8), не меньше нуля. Для выбранного простого правила — абсолютная
ошибка того же правила. Калибровка раздельная для апреля–июля и остальных месяцев
по дате решения, минимум 60 значений на горизонт/сезон. Иначе используется весь
предыдущий год. Пересечение квантилей устраняется сортировкой до калибровки.
Для зависимых суточных рядов и меняющегося климата гарантии покрытия нет.

Сохраняются исходные прогнозы, MAE, покрытие, средняя ширина и interval score
80% (ширина + штраф 10× за выход факта за границу) по всем горизонтам и сезонам.
Сравнение с v1 — на пересечении идентичных дат/горизонтов; 2025 отдельно.
Статусы: преимущество точечного прогноза — положительная нижняя граница 90%
бутстрэп-интервала выигрыша по целым годам против каждого базового правила
и меньшая весенняя MAE; диапазон — покрытие ≥75% и за год, и весной.
Один лишь широкий интервал не считается улучшением: публикуется interval score.
Параметры не подбираются по результатам этой проверки. v1 сохраняется.
