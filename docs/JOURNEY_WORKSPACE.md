# Риски и рекомендации

В ZXC создание маршрутов удалено из интерфейса по решению автора ветки.
«Карта путей» снова содержит только карту. Рабочая вкладка переименована в
«Риски и рекомендации». Прежние ссылки module=routes/backhaul/journey открывают её.

## Что рассчитывается

Выбранные в боковой панели точка, сезон и дата решения определяют данные карточки М1
и записи road_events.csv. Конкретная дорога выбирается явно: один гидропост не
считается одной дорогой. Указываются дата проезда, масса машины и груза.

Реестр использует только записи, опубликованные не позже даты решения. Факты и
объявленные графики различаются. Отсутствие данных не означает открытие дороги.
Для закрытия дневная точность обрабатывается консервативно: весь день закрытия исключён.

М1 показывает условный риск физического закрытия к проезду с выбранным запасом.
Это не вероятность аварии, недовоза заказа или юридический допуск. Модель относится
к порогу 20 т, для большей массы процент не переносится. Административное открытие
и остальные причины недоступности не включаются в этот процент.

## Предложения

- Проверяются до семи дней перед указанным проездом, не раньше даты решения.
  Используется один выпуск прогноза, без получения будущих фактов. Более ранняя дата
  рекомендуется только при меньшем риске М1 и известном пределе, допускающем массу.
  Разница указывается в процентных пунктах, не как измеренная экономия бизнеса.
- Если масса превышает известный предел, рассчитывается необходимое уменьшение груза.
  Если пустая машина уже тяжелее предела, уменьшение груза не предлагается как решение.
- При закрытии уменьшение массы не снимает запрет. При неизвестном пределе требуется
  подтверждение владельца дороги, конкретная допустимая загрузка не выдумывается.

Таблица сравнения содержит источники и доступна для скачивания CSV.
Исторический расчёт всей цепочки А3 сохранён в отдельном раскрываемом разделе.

Создание маршрутов, заявки на рейсы и обратный груз не отображаются. Расчётные модули
предыдущих экспериментов сохранены как код для команды; они не вызываются новым экраном.
