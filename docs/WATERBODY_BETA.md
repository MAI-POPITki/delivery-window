# Водоёмы · бета

Дашборд → **Направление → Водоёмы · бета**, либо `?module=waterbodies`.
Сохранённый пример: Верх-Исетское водохранилище, Свердловская область,
Sentinel‑2 L2A, 01.06.2021 и 21.09.2021. Это наблюдение, не прогноз.

Повторно используется рабочая спектральная классификация паводкового М2.
Каналы приводятся к единой 20-метровой сетке UTM; clouds/shadows/snow/ice,
сомнительные пиксели и часть спектральных конфликтов исключаются.
Контрольная область — полигон OSM с буфером 8 пикселей. OSM не считается
датированной независимой разметкой берегов. Вне этой области вода не измеряется.

Основные показатели: площадь воды раньше и позже **на общей видимой части**,
разность, появление/исчезновение воды, доля совместно видимой области.
Нельзя вычитать полные наблюдаемые площади при разной облачности. Показываются
границы возможного изменения всей области из-за неизвестных пикселей; они
не учитывают ошибку классификации и не являются доверительным интервалом.
При общей видимости ниже 80% вывод об изменении в UI блокируется.

[Эксперимент](../reports/waterbody_beta.md) ·
[Сравнение расширений](../reports/extension_candidates.md).
На примере разность всего два пикселя: существенное изменение берега не доказано.
Для площади конкретного водоёма независимой датированной разметки нет.
Качество паводкового М2 на внешнем наборе не переносится автоматически на эту задачу.
Объём, глубина и судоходность по площади не вычисляются.

## Воспроизведение

`python scripts/download_waterbody.py` — каталог Earth Search, COG-вырезки и маски.
Сохранены source metadata, DN, сетка, радиометрия и SHA-256. Используются продукты
baseline 03.00/03.01 с явным scale и нулевым offset. Новые baseline ≥04 загрузчик
отклоняет до отдельной проверки гармонизации BOA offset у источника.

`python scripts/check_extension_candidates.py` — повторный расчёт масок,
чувствительность MNDWI, сценарии массы/погоды М3, общий отчёт.
`python -m unittest tests.test_waterbodies tests.test_http_range` — границы,
облака, совмещение, радиометрия, целостность и UI.

Для чтения COG применяется requests-based RangeReader через штатный opener rasterio:
сохраняются унаследованные proxy/CA trust и проверка TLS. Проверяются статус 206,
Content-Range и полнота байтов. Это позволяет читать только вырезки, не скачивая
многосотмегабайтные сцены целиком.
