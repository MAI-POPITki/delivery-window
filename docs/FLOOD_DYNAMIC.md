# Динамическое обновление паводковых данных

Во всех трёх режимах «Паводки» есть блок **«Актуальные данные и обновление»**.
Выбор участка запускает один фоновый загрузчик на процесс приложения. Первый
показ не ждёт сети. Кнопка «Обновить данные участка» ставит проверку в очередь;
повторные запросы ограничены минутой. Интерфейс проверяет изменения каждые 30 секунд.

| Данные | Автопроверка | Источник и смысл |
| --- | --- | --- |
| Уровень гидропоста | раз в 6 часов | Наземные замеры «Уровень-Спутник»; для Лены у Якутска также проверенный график «Метео ДВ» |
| GloFAS | раз в 6 часов | Готовый внешний ансамбль расхода seamless_v4, не менее 30 полных сценариев на 7 будущих суток |
| Sentinel-2 | раз в 12 часов | Поиск за последние 14 дней, существующее спектральное правило и контроль качества |

При ошибке источника повторная попытка возможна через 30 минут. Пока сервер спит
или остановлен, фоновая сеть не работает; после запуска проверки возобновляются.
Фоновый процесс не делает коммитов и пушей. Локальное хранилище работающего
Streamlit может исчезнуть при пересоздании сервера; постоянный архив требует
workflow или внешнего постоянного диска. GitHub cron работает только из ветки
по умолчанию; наличие workflow в ZXC не включает отдельный cron для этой ветки.

## Уровень и собственная М1

Текущие замеры хранятся в `data/flood/live_levels/` отдельно от неизменяемого
архива обучения `data/flood/levels/`. Есть исходные ответы, код поста, единицы,
дата измерения, время первого получения и SHA-256. Нули и отрицательные значения
допустимы. `prev_y` и другой прибор из графика «Метео ДВ» не смешиваются с рядом
поста; спутниковые высоты SWOT не заменяют наземные уровни.

Изменённая поставщиком величина сохраняется отдельной ревизией со своим временем
доступности. Повторное получение не делает запись известной раньше. При отсутствии
новых наблюдений прежние записи остаются, но их дата не меняется на сегодняшнюю.
На каждый участок показывается число дней с замерами за последние 31 сутки
перед последним измерением одного источника, без заполнения пропусков.

Загрузка свежих уровней **не запускает автоматически архивную М1 на сегодня**.
Для этого нужны примерно месяц непрерывных измерений, проверенная привязка
нуля шкалы и пакет модели/калибровки текущего года. Свежие значения видны отдельно,
а прогноз М1 и оценка М3 сохраняют явно выбранную архивную дату. Уровни разных
поставщиков не объединяются автоматически в обучающий ряд.

На проверке 13.11.2026 по Москве «Метео ДВ» реально вернул восемь замеров Лены
4–11 ноября. «Уровень-Спутник» за последние 45 суток наземных уровней этого поста
не выдал; SWOT не использован. Полнота других постов зависит от фактической выдачи.

## Публикация без частично записанных файлов

Источники обновляются независимо с блокировкой по участку и источнику.
Блокировка удерживается операционной системой и освобождается при завершении
процесса; оставшийся после прерывания статус «выполняется» не задерживает новый запуск.
JSON меняется атомарно, ошибки сохраняют последний корректный файл.
GloFAS проверяется до публикации; каждый новый динамический выпуск сохраняется
отдельно, а прежний первый выпуск дня остаётся совместимым с архивным форматом.
Просмотр прошлой даты выбирает только действительно полученный к ней выпуск.

Новый спутниковый результат сначала полностью строится и проверяется в скрытом
временном каталоге, затем целиком публикуется. Старые результаты не перезаписываются.
На последнем снимке дата просмотра автоматически следует за новой обработанной
съёмкой; явно выбранная архивная дата не изменяется.
Облака, снег и отсутствие сцены остаются неизвестным состоянием, а не отсутствием воды.

## Запуск и проверка

Основной `requirements.txt` включает зависимости фоновой обработки Sentinel-2;
для обычного запуска достаточно установить его. Автоматическое обновление
включено по умолчанию при открытии паводкового участка.

```bash
pip install -r requirements.txt
streamlit run app/dashboard.py

# Разовая загрузка всех участков или одного источника:
python scripts/refresh_flood.py --force
python scripts/refresh_flood.py --points lena_yakutsk --sources levels glofas --force

# Автономные тесты без фоновой сети:
OKNO_FLOOD_AUTO_REFRESH=0 OKNO_HYDRO_AUTO_REFRESH=0 python -m unittest discover -s tests -v
```

`OKNO_FLOOD_AUTO_REFRESH=0` отключает фоновые паводковые загрузки. Если отдельная
переменная не задана, учитывается общий флаг `OKNO_HYDRO_AUTO_REFRESH`.
Разовый CLI не зависит от фонового флага и соблюдает TTL, если не задан `--force`.
Статусы находятся в `data/flood/refresh/`, первоисточники уровней — в
`data/flood/live_levels/raw/`. Кнопки и статус не требуют доступа к GitHub.

При проверке из облачной среды уровни и GloFAS успешно загрузились; получено
50 сценариев на 13–19 ноября. Каталог Sentinel-2 доступен, но сетевой прокси
этой среды отклонил доступ к `sentinel2l2a01.blob.core.windows.net` (CONNECT 403).
Новая растровая сцена здесь не получена; старые проверенные снимки сохранены.
Для фактического обновления М2 серверу нужен HTTPS-доступ к STAC, сервису подписи
Planetary Computer и хранилищам исходных каналов. Доступность на конкретном хостинге
проверяется отдельно; успешное чтение каталога не доказывает загрузку растров.
