# М2: состояние льда по радарным снимкам Sentinel-1

Задача М2 — по снимку определить, что сейчас на реке: **вода / переход (ледоход, шуга) / лёд**.
Зачем: М1 угадывает лёд по погоде, М2 видит его по факту — в том числе там, где нет гидропоста —
и поправляет прогноз («по погоде лёд уже должен стоять, а на снимке ещё вода»).

### Метки и их ограничения
Метки автоматические — из спутниковых дат льда Лены (Qiu et al. 2026) в той же точке:
`ice` — между ледоставом и вскрытием (с отступом 7 сут); `water` — вне ледового сезона;
`transition` — ±7 сут от событий; `unknown` — сезоны после 2024 (меток нет; для живой проверки).
Ошибка самих дат ≈ 11 сут, поэтому `transition` лучше исключить из обучения или учить отдельным классом.

### Покрытие снимками над Якутией
| Годы | Снимков в год в точке | Метки |
| --- | --- | --- |
| 2015–2016 | 2–5 | есть |
| 2017–2021 | ~30 (раз в 12 дней) | есть — **основа обучения** |
| 2022–2024 | **0** (отказ Sentinel-1B) | — |
| 2025–2026 | 15–20 (Sentinel-1C) | нет — живая проверка |

Первый взгляд на данных: медиана VV — вода −17,4 дБ, лёд −13,0 дБ, переход −14,2 дБ.
Вода тёмная и гладкая, лёд светлый и шероховатый — классы разделимы.

## Как делать (рекомендуемый порядок)
1. **Маска русла.** В вырезке есть берега и острова. Для каждой точки: медиана летних вырезок `water`,
   пиксели темнее ~−18 дБ — русло. Признаки считать только по руслу.
2. **Простая база (час работы).** Логистическая регрессия или CatBoost на признаках по руслу: медиана,
   перцентили и std VV и VH, отношение VV/VH. Часто этого уже достаточно.
3. **Нейросеть.** Дообучение предобученной ResNet-18 на 2 каналах (VV, VH) — только если база упирается
   в потолок. Аугментации: повороты, отражения, шум.
4. **Честная проверка — по годам, а не случайно:** обучение 2017–2019, валидация 2020, тест 2021
   (вырезки одного сезона похожи — случайное разбиение завысит качество). Метрика — F1 по классам
   `water` / `ice`, отдельно смотреть ошибки около дат событий.
5. **Живая проверка:** прогнать модель на `unknown` 2025–2026 и сравнить с журналом фактов
   (`data/forecast_log/facts.csv`) и с погодой.

## Как встроить в М1 (что даст точность)
Самый простой и сильный способ — **отсечение распределения**. Если на снимке в дату d уверенно вода,
ледостав ещё не наступил → все сценарии М1 с ледоставом раньше d выбрасываются; если уверенно лёд —
наоборот. Для вскрытия так же. Это сужает диапазон прогноза ровно в те недели, когда решения дороже
всего. Выход М2 удобно отдавать как таблицу `point, date, p_water, p_ice` — её подхватит М1.

## Результат (обучено)

```bash
python scripts/train_m2.py     # маски русла, проверка «год вне обучения», финальная модель, отчёт
python scripts/m2_predict.py   # P(лёд) для новых снимков и даты событий (запускается каждый день в GitHub Actions)
```

- **Классификация лёд/вода:** точность **0,95** (F1 вода 0,94, лёд 0,96) на годах вне обучения, 1 111 размеченных
  снимков; по годам 2017–2021 — 0,94–0,99. Логистическая регрессия на тех же признаках — 0,94, то есть
  разделение по обратному рассеянию простое, тяжёлая нейросеть не обязательна. Отчёт — `reports/m2_metrics.md`.
- **Даты событий по ряду снимков:** вскрытие ±9,3 сут (у переправы Якутск ±7,2), ледостав ±13,9 сут — на уровне
  ошибки самих меток (~11 сут) и интервала между снимками (12 сут). Файл — `data/s1/events_auto.csv`.
- **Отсечение сценариев М1 по снимку** выигрыша не дало (2,88 → 2,94 сут): «лёд ещё стоит» до даты прогноза
  модель и так знает. Ценность М2 — в факте события там, где нет поста, и в живом состоянии реки.
- **Где встроено:** блок «Лена по радарным снимкам» в карточке пути (регион Якутия); автофакты вскрытия у
  переправы Якутск в журнале прогнозов (`data/forecast_log/facts_auto.csv`, ручные факты важнее).
- **Что можно улучшить:** маски русла у Кюсюра, Олёкминска и Жиганска маленькие (95–730 пикселей) — вырезку
  стоит сдвинуть на середину русла; признаки весенней «мокрой» поверхности (падение VV за 2–3 недели до вскрытия)
  как ранний сигнал для М1; ResNet-18 на вырезках — проверить, обгонит ли она 0,95.
