# Окно завоза

Вероятностный прогноз дат открытия и закрытия сезонных путей северного завоза (зимников и ледовых переправ) и планировщик отправок для сквозного мультимодального коридора снабжения.  
Только открытые данные (ERA5, Росгидромет, спутники MODIS/Landsat и Sentinel-1, сводки МЧС и публичные тарифы), без установки датчиков на месте. **Всероссийский кейс-чемпионат, кейс А3 («Северный завоз и изолированные территории»).**

## Суть решения для кейса А3

Переход от отправки грузов **по средним календарным датам** к упреждающему предзавозу **по квантильному прогнозу окна переправы** с оптимизацией **всей сквозной цепочки из 4 звеньев** (а не одного речного плеча):

1. **Магистральное ж/д плечо:** Хаб Сибири (Новосибирск / Тайшет) $\rightarrow$ ст. Нижний Бестях (АЯМ, 6 суток в пути, `8 500 ₽/т`).
2. **Правый берег («Нижний Бестях»):** перевалочный буфер, простой вагонов и охраняемое хранение застрявшего перед закрытой рекой груза (`450 ₽/(т·сут)`).
3. **Сезонная переправа через р. Лену (узкое место):** штатный паром / ледовая дорога (`1 800 ₽/т`, пропускная способность выделенного слота $Q_{\max} = 45$ т/сут при суточном спросе $d = 25$ т/сут $\rightarrow$ чистый ресурс накопления предзавоза $Q_{\max} - d = 20$ т/сут) против аварийной переброски СВП «Хивус» / вертолётом Ми-8 в распутицу (`35 000 ₽/т`).
4. **Левый берег («ТЛЦ Якутска»):** страховой и предзавозной запас (`150` / `280 ₽/(т·сут)`) против потерь от дней дефицита и срыва поставок (`240 000 ₽/сут`).

## Как повторить расчёт и запустить дашборд

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt    # requirements-data.txt — если пересчитывать спутниковые GeoTIFF / Sentinel-1

# 1. Полный пересчёт базового контура (данные → проверки → М1 → региональное «до/после» → сайт)
python run_all.py

# 2. Пересчёт контура кейса А3 (тарифы и МЧС → валидация V1–V7 → физика Стефана → 5-квантильная модель → 4 звена коридора)
python okno_data/download_data.py --prices
python scripts/validate_data.py
python src/ice_physics.py
python src/model_window.py
python src/corridor_simulator.py

# 3. Автотесты (24 модульных и UI-теста)
python -m unittest discover -s tests -v

# 4. Запуск интерактивного дашборда
streamlit run app/dashboard.py
```

При запуске открывается приветственный экран «Окно завоза» («Открыть дашборд» / «Скачать описание проекта (PDF)»). Внутри дашборда доступны 5 вкладок: **«Карта путей»**, **«Прогноз по пути»**, **«Планировщик завоза»**, **«Сквозной коридор (А3)»** и **«Рейтинг риска»**.

**Автообновление данных:** каждый день в `06:00 МСК` GitHub Actions (`.github/workflows/daily-update.yml`) докачивает свежую погоду ERA5 и оперативный прогноз на 16 дней, обновляет радарные снимки Sentinel-1, пишет журнал прогнозов, перепроверяет данные и пересобирает страницу проекта. Перед локальной работой выполняйте `git pull`.

## Модели и физическая верификация

1. **Калибровка систематического сдвига спутника по сводкам МЧС (`V4`):** оптический индекс `Qiu et al., 2026` фиксирует появление талой воды на поверхности льда на 2–3 недели раньше фактического ледохода (в 2024 г.: спутник `2024-04-27` против ледохода у Якутска `2024-05-15`, разрыв `+18 сут`). В `src/validate_data.py` вычислена поправка сдвига (`+11,3 сут` к ледоходу, остаточный MAE `2,44 сут`).
2. **Физическое ядро (закон Стефана):** толщина пресноводного льда рассчитывается через накопленные градусо-дни мороза $\mathrm{FDD}$; коэффициент $\alpha = 1{,}683\ \text{см}/(^\circ\text{C}\cdot\text{сут})^{0,5}$ откалиброван на 6 096 реальных замерах Росгидромета ($R^2 = 0{,}580$, MAE `20,1 см`).
3. **Квантильный градиентный бустинг (`CatBoost MultiQuantile`):** предсказывает квантили `q10 / q20 / q50 / q80 / q90` даты закрытия и открытия окна без утечки будущих сезонов (*Leave-One-Season-Out* + конформная поправка). На переправе Якутск — Нижний Бестях MAE прогноза закрытия в аномально ранние вёсны снижена на **+28,8 %** (`5,85` $\rightarrow$ `4,16 сут`), осеннего открытия переправы 20 т — на **+17,5 %** (`12,35` $\rightarrow$ `10,19 сут`).
4. **Планировщик сквозного коридора (`okno/corridor.py`) и М3 (`okno/planner.py`):** переводит квантильный прогноз (`q20` для раннего закрытия весны) в график отгрузки из сибирского хаба с учётом ж/д плеча $\tau_{\text{rail}} = 6$ сут и пропускной способности переправы $N_{\text{pre}} = \lceil (d \cdot D_{\text{gap}}) / (Q_{\max} - d) \rceil$.

## Чек-лист «Что проверить перед применением» (Pre-deployment checklist)

1. **Свободная ёмкость целевого склада ТЛЦ:** готовность склада на изолированном берегу принять единовременно `+40–60 %` объёма (до 550–700 т пикового запаса перед закрытием переправы) и наличие температурных камер для скоропортящихся грузов.
2. **Провозная способность подходов ($Q_{\max} > d$):** наличие свободных слотов на паромах или ледовой переправе за 30–40 суток до закрытия, чтобы упреждающий предзавоз не создал искусственную очередь на причале.
3. **Оборотный капитал закупщика:** готовность заморозить оборотные средства в товарном запасе на 2–4 недели раньше стандартного календарного графика ради исключения аварийного тарифа СВП/авиации.
4. **Локальная калибровка спутника:** наличие минимум 3–5 исторических дат фактического закрытия переправы и открытия паромной навигации (приказы Минтранса региона / сводки ГУ МЧС) для расчёта локальной константы сдвига спутникового индекса таяния.

## Масштабируемость: как перенести решение на другой коридор

Для развёртывания на переправе **Салехард — Лабытнанги (р. Обь)**, зимниках ЯНАО, Чукотки, Таймыра или северных районов Красноярского края и Иркутской области:
1. Добавить координаты переправы и ближайшего гидропоста в `okno/regions.py` / `scripts/download_data.py` и выгрузить суточный ряд ERA5.
2. Собрать 3–5 архивных дат приказов регионального Минтранса / МЧС о закрытии переправы для калибровки сдвига спутникового ряда (`src/validate_data.py`).
3. Пересчитать локальный коэффициент Стефана $\alpha$ (`src/ice_physics.py`) и квантильные пороги `CatBoost` (`src/model_window.py` / `scripts/train_m1.py`).
4. Подставить региональные тарифы ж/д/автоподхода, переправы и хранения в `data/rosstat_prices/` или ползунки вкладки **«Сквозной коридор (А3)»**.

## Отчёт об использовании и верификации ИИ

ИИ-инструменты применялись для первичного поиска открытых научных наборов данных (`Qiu et al., 2026`; `Shiklomanov et al.`), генерации шаблонов кода пайплайна загрузки, модульных тестов и вёрстки интерактивного дашборда. Вся физическая и экономическая верификация выполнена через автоматизированные проверки (`scripts/validate_data.py`, `src/validate_data.py`): сверка температурных рядов ERA5 с климатической нормой Росгидромета у Якутска, отсев артефактов замеров толщины льда и сверка спутниковых дат с оперативными сводками ГУ МЧС по РС(Я) за весну 2019–2024 гг. — именно эта проверка выявила систематическое опережение оптического спутникового индекса начала поверхностного таяния относительно фактического ледохода на 2–3 недели и предотвратила смещение расчётов логистического окна.

- **Гидропосты Росгидромета (1970–2012):** Shiklomanov A. et al. *Data of river ice timing and thickness for selected river gauges in Russian pan-Arctic over 1970–2012.* Arctic Data Center, `doi:10.18739/A22Z12Q02`.
- **Спутниковая фенология льда р. Лены (2001–2024):** Qiu et al., 2026, *ESSD* — даты ледостава и начала таяния по сетке 3 км, `doi:10.5281/zenodo.17054619` (CC BY 4.0).
- **Метеорологический реанализ (1979–2026):** ERA5 (Hersbach et al., 2020) через Open-Meteo Historical & Forecast Weather API.
- **Радарные снимки (М2):** Copernicus Sentinel-1 GRD (Microsoft Planetary Computer STAC).
- **Оперативные даты переправы и тарифы:** приказы Минтранса РС(Я) и сводки ГУ МЧС России по РС(Я) (2019–2024), тарифные справочники АО «АК «ЖДЯ», ООО «Паромы Якутии», перевозчиков СВП и региональная статистика Саха(Якутия)стата.
