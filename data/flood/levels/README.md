# Измеренные уровни для собственного М1

Источник: публичные read-only API [Уровень-Спутник](https://level-satellite.ru),
авторы П. П. Головлев и А. И. Иннокентьев. Сбор: `scripts/download_flood_levels.py`.
Рядом с каждым исходным JSON.gz — манифест с запросом, временем получения,
SHA-256 распакованного ответа, метаданными станции и исходным описанием источников.
Публичная доступность не означает установленной нами открытой лицензии;
сведения об условиях использования следует уточнять у владельца источника.

Сохраняется полный ответ; обучение фильтрует только `level` и выбранный источник:
3045/11412 — gmvo, 19063/19054 — vodinfo. Источники не объединяются, расход
не используется. 12014 (Курган) сохранён для аудита, но в обучение не допускается.
Уровень — см над нулём поста; отрицательные числа допустимы. Пропуски сохраняются.

Подробнее: [метод и ограничения](../../../docs/FLOOD_M1.md).
