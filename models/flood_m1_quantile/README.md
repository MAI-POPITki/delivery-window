# М1 уровней v2

Модель `{point_id}_{year}.cbm` работает для дат решения указанного года.
Рядом JSON: станция/источник/SHA-256 архива, признаки, конец обучения,
калибровочный год, выбранные методы, MAE и сезонные поправки диапазона.
2019–2024 для Якутска/Ишима, 2019–2026 для Оренбурга/Орска.
Наличие версии 2026 не означает наличия текущих измерений: прогноз без них запрещён.

Обучение: `python scripts/train_flood_m1_quantile.py` из корня проекта.
`validation.json` описывает повторную архивную оценку, а не независимую сертификацию.
Подробности: [метод](../../docs/FLOOD_M1.md), [протокол](../../docs/FLOOD_M1_V2_PLAN.md).
