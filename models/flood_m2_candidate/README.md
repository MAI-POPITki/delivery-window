# Кандидат М2 по независимой ручной разметке

CatBoostClassifier на спектральных/пространственных признаках S2Hand
Sen1Floods11. Это Sentinel-2 L1C TOA. Рабочая карта использует L2A BOA:
веса не подменяют производственный классификатор без проверки переноса.

Порог 0.4 выбран только по 30 validation-чипам. Обучение — фиксированные
80 чипов. Все 90 test и 15 Bolivia исключены из обучения/подбора порога.
Хеш модели и точные имена train/valid: metadata.json.

Воспроизведение: scripts/benchmark_flood_m2.py; --evaluate-only применяет
сохранённую модель без переобучения; --report-only собирает таблицы из CSV.
Источник/хеши: data/flood/benchmark/manifest.json. Сотни МБ GeoTIFF не включены
в Git; скрипт скачивает их из открытого источника и проверяет сохранённые хеши.
